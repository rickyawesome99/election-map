# RDH 2024 precinct downloads (manual)

The Redistricting Data Hub requires a free account and forbids scripted downloads. Log in at
https://redistrictingdatahub.org/ then open each dataset page below and download the zip (the
"precinct boundaries + results" shapefile package). Save every zip unchanged into
`data-entry/precincts/raw/rdh/` (gitignored). The anchor builder reads them by state code in the
zip name (`xx_2024_gen_prec*.zip`), so the original filenames are fine.

Credit line required on /sources: "This map was created using data from the Redistricting Data Hub."

## MEDSL files behind a Dataverse guestbook (manual, two files)

`scripts/precincts/fetch_medsl.py` fetched 2016, 2022 and all 51 state files for 2024, but the 2018 and
2020 national state-office files sit behind a Harvard Dataverse guestbook (name / email / purpose form),
which the API refuses to bypass. Download them in a browser and drop them at the paths below:

| Year | Dataset | File | Save as |
|---|---|---|---|
| 2020 | https://doi.org/10.7910/DVN/OKL2K1 | STATE_precinct_general.csv (1.2 GB) | `data-entry/precincts/raw/medsl/2020/STATE_precinct_general.csv` |
| 2018 | https://doi.org/10.7910/DVN/ZFXEJU | STATE_precinct_general.csv (1.9 GB) | `data-entry/precincts/raw/medsl/2018/STATE_precinct_general.csv` |

Choose "Original File Format" in the download menu. Re-running the fetch script afterwards skips files whose size already matches.
