# Archive

Pages that have come off the site but are kept for their design. Nothing in this folder is built,
type-checked, linted, or scanned for Tailwind classes (`tsconfig.json` exclude, `eslint.config.mjs`
ignore, `@source not` in `app/globals.css`), so nothing here can reach the live site.

Each page gets its own folder whose `app/`, `components/` and `data/` subfolders mirror the paths the
files had in the project, so restoring a page is copying them back.
